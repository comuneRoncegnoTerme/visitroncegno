# Asset Museo della Musica

La pagina usa per ora `public/images/musei/demo-musica.svg` come fallback demo.

Per sostituirlo con fotografie reali, caricare qui preferibilmente:

- `hero.jpg` — esterno o sala iconica del museo
- `strumenti.jpg` — collezione / parete di strumenti
- `gioiello-1.jpg` — strumento storico in primo piano
- `gioiello-2.jpg` — dettaglio della collezione
- `gioiello-3.jpg` — sala o strumento caratteristico
- `parco-musicale.jpg` — area esterna / Parco Musicale

Dopo il caricamento, aggiornare `app/musei/museo-della-musica/page.module.css` per usare gli asset reali.
